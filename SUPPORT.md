# Getting help

- **Questions and usage problems:** open an issue with the question form in the project's repository, or a discussion if the project has Discussions turned on.
- **Bugs:** open an issue with the bug report form, including the steps that reproduce it.
- **Security vulnerabilities:** never open an issue. Report them privately, as [SECURITY.md](https://github.com/519lab/.github/blob/develop/SECURITY.md) describes.
- **Code of conduct concerns:** email conduct@519lab.com.

519lab projects are maintained on a best-effort basis. Outside the timelines in the security policy, response times aren't guaranteed.
