# 519lab/.github

Organization-wide defaults for 519lab. GitHub reads this repository's default branch and applies its files to every 519lab repository that has no file of its own. The repository has to stay public for that to work.

| File | Applies to |
| --- | --- |
| `SECURITY.md` | The security policy of every public 519lab repository without its own `SECURITY.md` |

This repository holds no workflows. The shared reusable workflows (`promote`, `version`, `release`) live in [`ggrace519/.github`](https://github.com/ggrace519/.github). Pin them to a release commit SHA there, never to a copy here.
